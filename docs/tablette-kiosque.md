# Préparer une tablette verrouillée sur Préambuléo

Objectif : le patient ne voit que le questionnaire. Il ne peut ni quitter l'application, ni ouvrir un navigateur, ni toucher aux réglages.

Le verrouillage se fait à deux niveaux :

1. **Dans l'application** : plein écran, écran toujours allumé, et code du cabinet pour sortir du mode patient.
2. **Sur la tablette** : une fonction du système qui bloque l'appareil sur une seule application. C'est elle qui empêche réellement d'en sortir.

Ces réglages sont à faire une fois, avant de remettre la tablette au cabinet. Les noms des menus changent un peu selon la marque et la version : à vérifier sur le modèle acheté.

## Étape commune : installer l'application

1. Ouvrir Chrome (Android) ou Safari (iPad) à l'adresse de l'application.
2. Menu du navigateur, puis « Installer l'application » ou « Sur l'écran d'accueil ».
3. Lancer Préambuléo depuis son icône : elle s'ouvre sans barre d'adresse, donc sans accès à Internet.
4. Dans l'espace praticien, changer le code de sortie (1234 par défaut).

## Tablette Android

**Solution simple : l'épinglage d'application**

1. Réglages, Sécurité, « Épinglage d'application » : activer, et exiger le code de déverrouillage pour désépingler.
2. Définir un code de verrouillage de la tablette, connu du cabinet seulement.
3. Ouvrir Préambuléo, afficher les applications récentes, toucher l'icône de l'application puis « Épingler ».
4. Pour sortir : maintenir Retour et Récents, puis saisir le code de la tablette.

**Solution robuste pour un parc de tablettes : le mode kiosque**

Une application de kiosque ou une gestion de flotte (mode « appareil dédié » d'Android) démarre la tablette directement sur Préambuléo et bloque tout le reste, même après un redémarrage. À prévoir quand il y aura plusieurs cabinets équipés.

## iPad

1. Réglages, Accessibilité, « Accès guidé » : activer et définir un code.
2. Ouvrir Préambuléo, appuyer trois fois sur le bouton principal (ou latéral), puis « Démarrer ».
3. Pour sortir : triple appui, puis le code.

Pour un parc d'iPad, le « mode application unique » se configure avec un outil de gestion de flotte.

## Autres réglages utiles

- Désactiver les notifications et les mises à jour automatiques pendant les heures d'ouverture.
- Luminosité fixe, mise en veille désactivée (tablette branchée sur son support).
- Wi-Fi du cabinet uniquement, aucun compte personnel sur la tablette.
- Support antivol et produit désinfectant compatible écran.

## Limites à connaître

- Sans l'étape « tablette », un patient peut quitter le plein écran avec un geste du système. Le code du cabinet protège l'espace praticien, pas la tablette entière.
- Une véritable application distribuée sur les magasins d'applications n'est pas nécessaire pour obtenir ce verrouillage. Elle pourra venir plus tard si des cabinets le demandent.
